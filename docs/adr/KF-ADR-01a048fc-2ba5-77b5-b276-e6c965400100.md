# KF-ADR-01a048fc-2ba5-77b5-b276-e6c965400100: Work recovery consumes one planned authority cut

- Status: accepted; contract landed in PR #3555; semantic authority behavior landed in PR #3574; stale unbound ambient-attempt recovery is tracked by PR #3577
- Date: 2026-08-28

## Context

Assignment lifecycle authority, WorkRef identity, WorkConsole and
SessionAttempt carriers, leases, and continuation decisions are intentionally
separate concepts. Fresh recovery nevertheless crosses all of them. The
current recovery path first builds a rooted plan, then reopens ambient Profile,
workspace, Console, WorkRef, and Assignment readers while applying that plan.
Those second discoveries can reject unchanged Work because a query proof,
reader projection, process attempt, or Profile locator changed.

The retained lifecycle boundary is also expressed as every status field except
`query_proof_root` and `work_semantics`. That exclusion list makes new reader
fields authoritative by default. In parallel, Assignment orchestration, Work
semantics, and the recovery continuation marker each derive a next action.
These are false conflicts and duplicate derivations, not reasons to weaken
stable identity, lifecycle, attempt, lease, generation, fence, root, or replay
checks.

The source audit is frozen in
[`work-authority-topology-v1.json`](../../framework/assignment-runtime/work-authority-topology-v1.json).
It is a qualification inventory, not runtime authority.

## Decision

### One typed authority flow

Work recovery uses these versioned semantic roles:

1. `kungfu.work.retained-assignment-authority/v1` contains only admitted
   Assignment identity and lifecycle facts owned by Assignment Runtime.
2. `kungfu.work.planned-profile-source/v1`,
   `kungfu.work.planned-target/v1`, and
   `kungfu.work.planned-console-binding/v1` retain the exact historical
   identities selected while planning.
3. `kungfu.work.current-recovery-observations/v1` carries fresh availability,
   liveness, revision, generation, attempt, lease, fence, and query evidence.
   Observations may reject a stale plan but cannot replace its authority.
4. `kungfu.work.continuation-decision/v1` is the sole semantic next-action
   projection. Assignment orchestration owns its derivation. Other surfaces may
   add explicit execution precondition failures but cannot derive another Work
   action.

Plan creation is the only authority-discovery stage. Apply consumes the exact
planned inputs and performs verification only. A Profile, workspace, Console,
WorkRef, Assignment, or authorized transition discovered after the plan cut is
a topology violation, even if a forwarding wrapper hides the discovery.

### Work and executor continuity remain separate

Stable WorkRef coordinates identify the Work. WorkConsole is stable runtime
continuity for that Work view. SessionAttempt and process observations identify
one executor attempt. Assignment and Agent leases fence their respective
mutations. A new query proof or SessionAttempt does not create a new WorkRef or
WorkConsole; a genuine stable-coordinate, source-root, generation, attempt,
lease, fence, or lifecycle mismatch still fails closed.

Before native single-writer resolution, Agent Session may reap an expired
native Codex ambient attempt only when its observer evidence has expired and
it has no effective Work binding. That cleanup records the orphaned attempt,
observer disconnection, recovery receipt, and defensive lease release. An
active attempt or any attempt bound to Work remains authoritative and fails
closed; this exception cannot bypass Work, lease, fence, lifecycle, or replay
identity.

### Qualification budget

Each semantic identity has at most one writer or deriver, and recovery has zero
post-plan authority rediscovery sites. The topology inventory records current
debt explicitly and must decrease monotonically. File splitting, aliases,
forwarding wrappers, exclusion lists, caches, compatibility adapters, or a new
aggregate status object do not reduce the count.

## Consequences

- Recovery plans become larger and more explicit, while apply becomes smaller
  and deterministic.
- Reader projections can evolve without changing lifecycle equality.
- A dead unbound ambient process cannot remain a false competing writer, while
  every Work-bound attempt retains the existing fail-closed boundary.
- CLI, GUI, Agent, Profile, and recovery surfaces expose the same semantic next
  action while retaining surface-specific execution diagnostics.
- Existing plans and registries require bounded compatibility readers until the
  versioned migration is complete; compatibility never selects new authority.
- The decision is false if apply discovers an authority source, if a current
  observation replaces a planned identity, if more than one component derives
  the semantic next action, or if any genuine identity, lifecycle, attempt,
  generation, lease, fence, root, idempotency, or replay mismatch stops failing
  closed.
