# KF-ADR-019f86da-4f90-716a-b49f-3ffe646d3c88: Xinfa context quality is a deterministic adversarial ratchet

- Category: Xinfa / verified context / qualification

## Decision

Xinfa context quality is qualified against one exact compiled Atlas and a
versioned, product-owned corpus. The corpus carries explicit gold critical
sources, bounded optional sources, structured task intent, token budgets, and
expansion limits. It spans implementation, review, incident diagnosis,
documentation update, cross-domain impact, and continuation across eleven
non-isomorphic route families.

Qualification is deterministic and runs only public Xinfa interfaces. It
measures critical-source recall, required omissions, irrelevant-context token
ratio, route ambiguity, degraded output, stale-root detection, required
human correction, all-surface fallback, token cost, and expansion hops. It
also injects stale Atlas roots, unknown required authority, and insufficient
budgets. A stale binding is an explicit rejection; missing authority or budget
must never produce a complete false green.

The retained qualification receipt binds the corpus root, Atlas root, Project
Cut root, thresholds, per-case outcomes, metrics, and qualification root. The
corpus checker freezes minimum case, route, and scenario breadth and rejects
weakened thresholds. Changes may improve a metric or add cases, but may not
silently lower a ratchet.

## Authority and non-goals

The project owns route declarations and domain-specific gold oracles. Xinfa
owns route resolution, bounded projections, omissions, roots, and the
qualification format. The benchmark does not introduce an LLM judge, embedding
authority, Shifu-side selector, or second semantic graph. Human review may
change the declared corpus in a successor cut; it is not a runtime correction
channel that can hide an ambiguous or degraded result.

## Falsification

The decision is violated if a critical source is omitted, an undeclared source
exceeds the relevance ceiling, a route is ambiguous, output silently degrades,
a stale root is accepted, missing authority or a one-token budget yields a
complete result, an all-surface route is used as fallback, or the retained
receipt cannot be reproduced from its bound Atlas and corpus.
