# KF-ADR-019f86da-4f90-7cb5-b65c-b463768e7ae8: Fact-Episode Ontology is distinct from Action Geometry

- Status: accepted boundary; successor machine split and compatibility
  migration remain staged
- Date: 2026-07-20
- Category: KFD-7 / ontology / action semantics
- Related: [KF-ADR-019f86da-4f90-786d-aa24-a97705e13917](KF-ADR-019f86da-4f90-786d-aa24-a97705e13917.md),
  [KF-ADR-019f86da-4f90-7c45-8d95-3745dcbbff1c](KF-ADR-019f86da-4f90-7c45-8d95-3745dcbbff1c.md),
  [KF-ADR-019f86da-4f90-7b96-bc7d-4555833303eb](KF-ADR-019f86da-4f90-7b96-bc7d-4555833303eb.md), and
  [KF-ADR-019f86da-4f90-77c0-827b-fe1a3aa43e2b](KF-ADR-019f86da-4f90-77c0-827b-fe1a3aa43e2b.md)

## Context

KF-ADR-019f86da-4f90-77c0-827b-fe1a3aa43e2b correctly separated cross-domain semantics from adopter-owned Domain
Profiles, but some prose and combined-v1 contracts still flattened Fact,
Episode, Pursuit, Atlas, and Warrant into five peer Action Geometry roles.
That obscures a more stable distinction already present in the runtime:

- Fact and Episode describe what the contract world contains as admitted state
  and realized causal occurrence; while
- Pursuit, Atlas, and Warrant constrain how an intelligent participant acts in
  that world through direction, perspective, and authority.

Calling all five Action Primitives makes Episode look like a fourth action
coordinate and Fact look like a fifth role. Calling the higher layer a
"substrate" is also insufficient: substrate is a useful implementation term,
but it does not state the semantic relation that every Domain Profile must
preserve.

## Decision

### 1. Fact-Episode Ontology is the semantic foundation

**Fact-Episode Ontology** is the canonical KFD and Kungfu term for the
contract-world distinction:

```text
Fact     admitted state at an explicit authority and evidence Cut
Episode  realized causal occurrence between declared Cuts
```

Facts define admitted state. Episodes preserve realized causal occurrence.
Together they form the ontology over which Action Geometry operates. This is
not a claim that Kungfu enumerates all reality or provides an absolute
observer-independent world model.

Kungfu may call its concrete journal, content, admission, query, lifecycle, and
replay implementation the **Fact/Episode runtime substrate**. That term names
implementation support, not a competing ontology or a higher normative layer.

### 2. Action Geometry has three action Primitives

Action Geometry is the cross-domain responsibility model over the
Fact-Episode Ontology:

```text
Pursuit  direction
Atlas    perspective and accepted Cut
Warrant  bounded authority
```

Episode is not a fourth Action Geometry coordinate. It records the realized
path through the ontology. Fact is not another action role. It supplies the
admitted state against which the three coordinates are resolved.

The valid-action intersection, non-substitution invariants, conservative
session projection, and `ActionBinding` semantics remain unchanged.

### 3. Domain Profiles declare a two-plus-three mapping

A Domain Profile declares five inspectable mappings in two semantic groups:

```text
two ontology bindings       Fact, Episode
three action mappings       Pursuit, Atlas, Warrant
```

This grouping does not require five records, stores, APIs, services, commands,
or interface components. Semantic independence and traceability remain the
qualification target.

### 4. Combined-v1 identities remain compatibility facts

The existing Agent Work v2 "four-role" contract, KFD-7 `roles[]` array,
`actionProfile`, `actionContract`, Profile protocol ids, roots, receipts, and
qualified evidence cuts keep their original bytes and identities. Current
readers remain supported.

Machine discovery may add an explicit semantic-layer projection that classifies
the existing values as two ontology bindings and three Action Geometry
mappings. It must not relabel an old root, remove an old field, or claim that a
historical activation cut used a successor encoding.

### 5. Relationship to KF-ADR-019f86da-4f90-77c0-827b-fe1a3aa43e2b

This decision supersedes only the part of KF-ADR-019f86da-4f90-77c0-827b-fe1a3aa43e2b that could be read as making
Fact and Episode peer Action Geometry responsibilities. KF-ADR-019f86da-4f90-77c0-827b-fe1a3aa43e2b remains
authoritative for Domain Profile separation, compatibility identities,
authority boundaries, semantic independence, and the staged successor split.

## Qualification

The boundary is qualified only when:

- human and agent vocabulary expose the same ontology/geometry distinction;
- machine discovery reports the two-plus-three grouping without changing
  combined-v1 roots or readers;
- KFD-7 Domain Profile declarations still require all five inspectable
  mappings;
- runtime and release checks continue to reject invalid cross-layer
  inferences; and
- no verifier infers semantic separation from physical component count.

## Consequences

Kungfu gains a smaller and more legible model:

```text
Fact-Episode Ontology
  -> Action Geometry
  -> Domain Profile
  -> product presentation
```

The distinction also aligns the public philosophy with the implementation:
KFD names the ontology, while Kungfu realizes it through journal-backed
Fact/Episode runtime substrates and provider-neutral projections.
