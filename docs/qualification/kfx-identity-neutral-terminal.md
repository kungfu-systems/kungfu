# KFX identity-neutral terminal qualification

This is the sole terminal product-cut gate for the native KFX foundation,
Passport-to-Warrant authority, capability enforcement, identity-neutral
cutover, Control Suite recursive dogfood, and Agent Work Lab Suite. It
supersedes the unexecuted
`2026-07-28-kungfu-kfx-agent-work-lab-terminal-qualification` Assignment.
Supersession is recorded through the native Assignment family lifecycle; it
does not rewrite either immutable request.

## Authority statement

The terminal contract uses these terms precisely:

- KFD is the common evaluation standard and produces eligibility evidence. It
  does not authorize execution.
- A Release Passport proves one exact artifact and its source, dependency,
  Buildchain, verifier, publisher, and qualification roots. It does not grant a
  purpose.
- Work and its Warrant authorize one purpose against exact predecessor roots.
  High-consequence capability, migration, policy, trust-root, key-rotation,
  global-administration, Core-update, and emergency-recovery purposes require
  an explicit owner or threshold Warrant.
- A capability grant is the runtime power ceiling. Every physical host
  rechecks the exact package, Cut, generation, Warrant, grant, placement, and
  isolation roots before execution.
- Product System is inert assembly and distribution metadata. First-party,
  System, fixed names, bundle paths, installer origin, signers, and KFD status
  contribute zero authorization weight.

## Executable gate

Run the source campaign:

```bash
./shifu qualify:kfx-identity-neutral-terminal
```

Run the Mac packaged campaign after producing an unpacked application:

```bash
./shifu product gui build
./shifu qualify:kfx-identity-neutral-terminal -- \
  --packaged-root product/dist/desktop \
  --report /tmp/kfx-identity-neutral-terminal-report.json
```

The report is evidence, not an authority store. It roots the exact source,
contract, native campaign, Agent Work Lab catalog, package tree, and observed
outcomes. Final authority remains the admitted Fact/Work/Warrant/Cut,
protected-PR review, merge evidence, and native Assignment decision.

## Qualification matrix

| Invariant | Executable evidence |
| --- | --- |
| Bundled and ecosystem-equivalent evidence has one decision | native Control Suite product/user-root symmetry campaign |
| KFD or identity alone grants no authority | KFD-only, identity-only, missing-Warrant, and high-consequence refusal fixtures |
| False System/first-party/Product claims fail closed | native request-forgery campaigns and manifest-key scan |
| Passport replay, sibling, expiry, revocation, publisher, verifier, policy, capability, plan, Cut, and generation drift fail closed | native assessment, apply, host-authorization, and recursive Control Suite campaigns |
| Accepted operations are reconstructable | Work/Warrant/Episode/Settlement/Cut history and exact host authorization roots |
| One writer and deterministic recovery | concurrent writer, crash/restart reconstruction, corrupted candidate, LKG rollback, and safe-mode campaigns |
| Every bundled KFX uses the public contract | complete `extensions/**/kungfu.kfx.json` matrix plus transport-only `package.json` checks |
| GUI, TUI, CLI, and Agent preserve the same roots | native Node/Python/API host parity and Profile Suite campaigns |
| Agent Work Lab is a normal public Suite | Suite manifest, catalog, Core/API/TUI/GUI tests, offline demo, real-run planning, requalification, and existing-Work-first routing |
| Mac product carries and runs the same Suite | unpacked app resource roots plus disposable-home packaged CLI first run and rerun; GUI/TUI consume the same packaged manifests and bundles |
| Old authority paths remain absent | tracked-source reverse scan and retired-file assertions |

Source scans, `package.json`, generated reports, registry-history JSONL, and
process-local generations are never accepted as final authority. They can only
detect regressions or point to the exact native evidence that decides them.

## Platform and release boundary

Affected-native protected CI runs the required macOS, Linux, and Windows
contracts for the exact pull request and merge group. The interactive packaged
product campaign is retained on macOS ARM64 because this terminal does not
publish a release or claim a packaged Linux/Windows desktop experience.

This gate does not claim universal malware freedom, arbitrary native-code
safety, public marketplace readiness, third-party production adoption, or a
stable post-v4 compatibility promise.
